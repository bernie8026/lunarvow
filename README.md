# 月下誓約檔案庫

Bernie's Honkai Realm：以月下誓約為主題的靜態網站，包含攻略、劇情、角色圖鑑和圖片收藏。

網站可直接部署到 GitHub Pages，無需建置。開發時請用本機 HTTP 伺服器預覽；角色圖鑑需要透過 HTTP 讀取 `data/characters.json`。

## 驗證網站

需要 Node.js 20 或更新版本：

```sh
npm install
npx playwright install chromium
npm test
```

測試會啟動並關閉自己的本機伺服器，檢查八個頁面的手機及桌面排版、鍵盤導覽、減少動態效果模式、無 JavaScript 的導覽、圖鑑搜尋和重試、三語切換、儲存受限時的行為，以及音樂播放狀態。測試用的 Playwright 不會載入到正式網站。

若電腦已有 Microsoft Edge，可設定 `BROWSER_CHANNEL=msedge` 使用它執行測試。

載入畫面會預載全部八個頁面，以及清單內的圖片、資料、樣式、程式和完整背景音樂。進度按成功完成的資源數計算（不是位元組百分比），並等待目前頁面及字型準備好才自動退場。圖片必須完成解碼，其他檔案必須完整讀取；單項下載超過 60 秒會列為失敗，提供重試。失敗項目不會計作成功；只有使用者主動略過才提早進入。減少動態效果模式保留載入檢查。

預載涵蓋網站子頁，並非 Git 分支或外部參考文章。圖鑑的第三方圖片及繁簡轉換程式也列入清單；外站不可用時會顯示失敗項目。瀏覽器可重用 HTTP 快取，但預載不保證離線存取，也不會預先執行其他頁面的程式。

新增／移除頁面或資源、修改角色圖片網址或音樂版本後，執行 `npm run build:preload` 並一併提交 `assets/preload-manifest.json`。`npm run check:preload`（亦包含於 `npm test`）會檢查清單是否過期。

音樂會在預載階段下載，但仍然只會在按播放後播放；音量及播放位置會在瀏覽器允許時儲存在本機。繁簡轉換設有內建後備字表，外部轉換服務暫時無法連線時仍可切換語言。
