- 無 JavaScript 時保留完整繁體內容及官方連結；狀態為核對日的快照，篩選控制隱藏。

## 維護

1. 核對各地區官方公告後修改 data/news.json，填寫三語內容、公告日期、來源與可確認的期限。
2. 同步 checkedOn、版本摘要、spotlight、homeItems；首頁選擇重點，完整列表按主題分區，同類內按公告日期排序。版本卡只填已核實的現行版本，未上線內容另作預告。
3. 執行 npm run build:news 更新兩頁靜態內容、assets/news-data.js，以及攻略／劇情／綜合資料頁的官方消息核對日期。
4. 新增或移除檔案後執行 npm run build:preload，讓完整消息頁、資料和程式都進入預載。
5. 執行 npm test。CI 檢查生成內容過期、資料、三語篩選、地區邊界、時間狀態、無 JavaScript、手機／桌面版面及原有功能。
